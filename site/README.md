# Salesforce Business Analyst Practice Quiz

Upload all files in the `site` folder to the root of a GitHub repository. Then enable GitHub Pages from the `main` branch and `/ (root)` folder.

## Features
- Try-again feedback for incorrect answers
- Explanations shown after a correct answer when available
- Previous/Next navigation
- Shuffle Questions button
- Restart Quiz button
- Mobile-friendly layout

**Note:** Shuffle Questions randomizes question order and starts a fresh attempt. Restart Quiz keeps the current question order and starts over.
